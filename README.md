## How I work

- Build and test in small, verifiable steps.
- Document setup, commands, expected output, and known limitations.
- Use Git for version control and GitHub Actions for automated checks where appropriate.
- Keep credentials, private keys, environment files, generated reports, and local dependencies out of version control.
- Distinguish tested functionality from planned or unverified functionality.
